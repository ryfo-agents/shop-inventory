# Greenfield UX Resources

The branch is guided by these resources:

- Nielsen Norman Group, 10 Usability Heuristics: https://www.nngroup.com/articles/ten-usability-heuristics/
- WCAG 2.2 Quick Reference: https://www.w3.org/WAI/WCAG22/quickref/
- WAI-ARIA Authoring Practices: https://www.w3.org/WAI/ARIA/apg/
- GOV.UK Design System: https://design-system.service.gov.uk/
- U.S. Web Design System accessibility guidance: https://designsystem.digital.gov/documentation/accessibility/
- IBM Carbon accessibility guidance: https://carbondesignsystem.com/guidelines/accessibility/overview/
- shadcn/ui: https://ui.shadcn.com/docs
- Figma MCP: https://help.figma.com/hc/en-us/articles/39216419318551-Get-started-with-the-Figma-MCP-server
- Storybook MCP: https://storybook.js.org/docs/11/ai/mcp/overview
- Playwright MCP: https://github.com/microsoft/playwright-mcp
- axe MCP: https://github.com/dequelabs/axe-mcp-server-public
- Lighthouse: https://developer.chrome.com/docs/lighthouse/overview/
- Core Web Vitals: https://web.dev/articles/vitals-measurement-getting-started
- Agent-oriented usability research: https://arxiv.org/abs/2605.02729

These are references for the evaluator and design decisions, not a requirement to import every library into the runtime. The greenfield client keeps the current static deployment shape while applying the interaction and accessibility principles directly.
