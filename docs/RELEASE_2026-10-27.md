## Rollback caution

The prior deployment is recorded, but promoting old code does not reverse schema changes and loses new version-precondition guarantees. For an incident, contain writes and verify compatibility before rollback; prefer a reviewed forward fix. Never restore the production archive blindly or reverse additive migrations without an explicit recovery plan.
